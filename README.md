# Mini Projeto SQL - Loja Tech

Este projeto foi desenvolvido para praticar os fundamentos de SQL utilizando MySQL.

## Objetivo

Simular um pequeno banco de dados de uma loja para praticar consultas e relacionamentos entre tabelas.

## Tecnologias

- MySQL
- SQL

## Estrutura do Banco

O banco possui três tabelas:

- Clientes
- Produtos
- Pedidos

As tabelas são relacionadas através de chaves estrangeiras.

## Conceitos utilizados

- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- LIKE
- BETWEEN
- IN
- IS NULL
- JOIN
- ALIAS

## Consultas realizadas

- Listagem de clientes
- Produtos por faixa de preço
- Clientes da cidade de São Paulo
- Pedidos por período
- Pedidos utilizando JOIN entre tabelas

## Aprendizados

Durante este projeto pratiquei a criação de bancos relacionais, inserção de dados, filtros, ordenação e consultas envolvendo múltiplas tabelas.
